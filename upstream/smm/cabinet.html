VK — Поиск и сбор аудитории парсинг

Ищите группы по теме, собирайте подписчиков конкурентов, находите самых активных и вычленяйте "горячую" аудиторию через пересечения.

Как работает: подключается к VK API через ваш токен. Результаты — файлы на сервере. Кнопка ⬇ скачивает файл к вам.

🔍 Поиск групп vk_search_groups

Что делает: находит сообщества VK по ключевым словам и возвращает список ссылок.
Для чего: узнайте, где сидит ваша аудитория — оттуда будете собирать подписчиков.
Пример: "алготрейдинг, крипта, пассивный доход" — получите 50+ групп по теме.
⏱ Настройки скорости
Для поиска групп — 1-3 сек достаточно.

👥 Сбор аудитории vk_collect_users

Что делает: собирает подписчиков из групп — ID, имена, города.
Для чего: база людей, уже интересующихся темой — для рассылки или таргетинга.
Вставьте 3-5 конкурентных групп — получите их аудиторию в JSON-файл.
⚠ Для закрытых/приватных групп VK ограничивает список участников — такие группы будут отмечены в отчёте (failed[]).
⏱ Настройки скорости
2-5 сек между запросами — защита от капчи.

⚡ Анализ активных пользователей vk_analyze_activity

Что делает: для каждой группы берёт посты стены, затем через likes.getList и wall.getComments собирает реальные UID лайкнувших и прокомментировавших — с подсчётом активности по каждому человеку.
Для чего: получить список реально активных людей (не просто подписчиков) с их статистикой. Фильтруйте по порогу лайков, комментов, числу групп.
Результат: active_users.txt (список ID) + active_users_stats.json (детальная статистика).
⏱ Задержка между запросами случайная
1-3 сек между likes.getList и wall.getComments запросами. Для больших групп увеличьте до 3-5 сек.

🎯 Пересечение аудиторий vk_audience_intersection

Что делает: собирает подписчиков из указанных групп через VK API и находит людей, присутствующих в ≥ N группах одновременно.
Для чего: человек из 3-4 тематических групп — ваш идеальный клиент. Пересечение — самая "горячая" база.
Также можно передать files (имена файлов с ID) вместо group_ids — для работы без запросов к API.
⏱ Настройки скорости
Задержка между pages getMembers. 1-3 сек безопасно.

🔬 Фильтр пользователей vk_parse_filter

Что делает: читает файл статистики (от Анализа активных или Пересечения), применяет пороговые фильтры и сохраняет очищенный список.
Для чего: дополнительная фильтрация без повторного парсинга — например, из 10 000 собранных оставить только тех, у кого ≥5 лайков в ≥3 группах.
Передайте имя JSON-файла со статистикой (active_users_stats.json или common_users_stats.json).

🎂 День рождения сегодня vk_birthday_today

Что делает: берёт любую ранее собранную или загруженную аудиторию и через официальный VK API оставляет людей, у которых сегодня день рождения.
Поддерживаемые источники: TXT, CSV, JSON, ссылки vk.com/id…, результаты пересечения, активности и других инструментов. Пользователи, скрывшие дату рождения, учитываются в итоговой статистике и не попадают в выборку.

Что делает: отправляет сообщение списку пользователей с задержками.

⚠ 30-90 сек. Слишком частые отправки → бан аккаунта.
